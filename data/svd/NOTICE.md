# SVD data

These files are the "patched" SVDs published by the stm32-rs project
(https://github.com/stm32-rs/stm32-rs, built at https://stm32-rs.github.io/stm32-rs/),
downloaded Oct 22, 2026. They are STMicroelectronics' CMSIS-SVD files with
community corrections and named field values added. See the stm32-rs repository
for upstream licensing. The MIT license in this repo covers RegLens's own code,
not these data files.
